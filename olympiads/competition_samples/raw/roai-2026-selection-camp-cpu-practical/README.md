## Why This Is Core CEOAI Preparation

Nitro describes this round as the Romanian selection camp for the teams that will represent Romania at IAIO and CEOAI. The tasks are unusually aligned with the current CEOAI syllabus:

- `Polyglot`: NLP embeddings, manifold alignment, nearest-neighbor/permutation recovery, CSV submission contract.
- `Too Easy Fairy`: CV feature extraction, DINOv2 patch embeddings, one-shot segmentation, Dice score.
- `Smart Warehouse`: reinforcement learning, TD updates, Q-learning/SARSA, hidden-scenario policy evaluation.

Use these as competition tasks, not reading material. A task counts only after a submission-like artifact exists.

## Files

- `polyglot.md`: embedding-space alignment task.
- `too_easy_fairy.md`: one-shot semantic segmentation from DINOv2 features.
