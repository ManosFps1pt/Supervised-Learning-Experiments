# Central European Olympiad in AI Syllabus

1. Reinforcement Learning (RL) and AI Search:
    (a) A* Algorithm and heuristics
(b) Minimax and variations
(c) Monte Carlo method
(d) Markov Decision Processes (MDPs)
(e) Temporal Difference Learning
(f) Q-learning
2. Machine Learning (ML):
    (a) Classical algorithms (classification and regression): Naive Bayes, Linear Regression,
       Logistic Regression, SVM, k-NN, Decision Trees
(b) Clustering: K-Means, K-Means++, DBSCAN, Hierarchical
(c) Ensemble Methods: Random Forests, Voting, Bagging, Boosting
(d) Dimensionality Reduction
3. Deep Learning (DL):
    (a) Neural Network Basics: Perceptron, MLP, Backpropagation
(b) Optimization Techniques: SGD, Adam, RMSProp, Learning Rate Schedules, Regu-
larization, Dropout, Batch Normalization
    (c) Architectures: CNNs, RNNs, LSTM, GRU, Transformers (attention mechanisms,
       BERT, GPT, Vision Transformers)
(d) Generative Models: Autoencoders, Variational Autoencoders (VAE), GANs, Diffusion
Models
4. Natural Language Processing (NLP)
    (a) Preprocessing: Tokenization, Stemming etc
(b) Embeddings: TFIDF, Word2Vec etc
(c) Related Architectures: Seq2Seq, T5, LLaMA etc
5. Computer Vision (CV):
    (a) Processing: Filtering, Edge Detection, Histogram of Gradient (HOG) etc
(b) CNN architectures: AlexNet, VGG, ResNet, Inception, EfficientNet
(c) Related Architectures: YOLO, Stable Diffusion, Vision Transformers (ViT) etc
