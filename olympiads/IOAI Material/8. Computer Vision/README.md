# Computer Vision

## Purpose

This lesson covers the highest-value Computer Vision items for CEOAI preparation
under time pressure.

The goal is not broad CV mastery. The goal is to:

- recognize the main CEOAI CV task types quickly
- build one image-classification baseline fast
- connect classic CV features to modern CNN-based workflows
- leave behind one visible competition-style artifact

This lesson should be treated as a sprint lesson, not a full course.

## Core Path

Start with:

1. `exercises/01_ceoai_cv_sprint_plan.md`

This sprint is complete only when it produces:

- an executed notebook with a CV baseline
- a metric such as validation accuracy or loss
- a small prediction table or image grid with predictions
- short recognition notes for HOG, edge detection, ResNet, YOLO, and ViT

## Scope

This lesson is aligned first to the local CEOAI syllabus:

- CV processing: filtering, edge detection, HOG
- CNN architectures: AlexNet, VGG, ResNet, Inception, EfficientNet
- related architectures: YOLO, Stable Diffusion, ViT

Lower-priority topics such as diffusion should stay at recognition level unless
the user explicitly asks to go deeper.
