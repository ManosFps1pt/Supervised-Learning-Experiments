# IOAI University Material

This folder contains the lessons taught so far by the university preparation program.

This is the main preparation guide for IOAI / CEOAI work in this repository.

## Folder Rule

Every lesson directory should use this structure:

```text
Lesson Name/
  sources/
  exercises/
```

- `sources/`: original university material, including notebooks, PDFs, Word documents, slides, datasets, and model files.
- `exercises/`: simple practice exercises generated by the AI coach to help me understand the concepts.

## No-Code Coaching Rule

The AI coach must not write solution code unless I explicitly ask for code.

Default behavior:

- explain concepts
- ask guiding questions
- design exercises
- review my code
- give hints
- point me to relevant source material
- help debug code I wrote

Do not default to writing implementations for me. The goal is for me to learn to code the solutions myself.

## Exercise Style

Exercises should usually contain:

- learning goal
- prerequisite source file
- task statement
- expected output or self-check
- hints, preferably progressive
- optional stretch task

Exercises should not contain full solution code unless I explicitly request it.
