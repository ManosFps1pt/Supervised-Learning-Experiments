# Exercises: 1. Basics

Use this folder for practice exercises based on the university basics lesson.

Source material is in `../sources/`.

Focus areas:

- Python fluency
- NumPy vectorization
- broadcasting and shapes
- pandas basics
- metrics
- train/validation split
- simple sklearn baselines
- small PyTorch sanity checks

No solution code should be generated here unless explicitly requested.

## Problem Sets

Work through these in order. Each file is a practice prompt, not a solution.

1. `01_vectorization_shapes.md` - NumPy vectorization, broadcasting, `einsum`, shapes, axis logic, and loop removal.
2. `02_pandas_features.md` - pandas grouping, `transform`, safe merges, raw-table cleaning, and feature construction.
3. `03_metrics_plots.md` - metric-first thinking, classification/regression metrics, thresholds, confusion matrices, and diagnostic plots.
4. `04_leakage_adversarial_validation.md` - data leakage, suspicious validation scores, and train/test distribution shift.
5. `05_pipelines_cross_validation.md` - train/validation splits, `Pipeline`, `ColumnTransformer`, fold-safe preprocessing, and splitter choice.
6. `06_pytorch_tensors_training.md` - PyTorch tensor layout, datasets, dataloaders, training loops, and overfitting one batch.
7. `07_gpu_memory_debugging.md` - device handling, CPU/GPU synchronization, memory pressure, dataloader throughput, gradient accumulation, and clipping.
8. `08_training_playbook_missing_data.md` - contest workflow, sanity checks, missing-data diagnosis, strategy comparison, and final debugging reflexes.
