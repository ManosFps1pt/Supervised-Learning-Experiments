- Difficulty: Easy
- Task type: classical ML / tabular regression
- Dataset status: downloaded

## Files

- `source/`: original downloaded materials
- `data/`: local dataset files or documented auth blocker
- `notebooks/`: editable starter/baseline notebooks only
- `notes/overview.md`: exercise prompt, evaluation, and submission format
- `notes/problem_summary.md`: syllabus and import summary

## Data Setup

The notebook expects Kaggle files in `data/`:
