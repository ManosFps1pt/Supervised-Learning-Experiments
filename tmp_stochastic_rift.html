The Stochastic Rift

Central European Olympiad in Artificial Intelligence

1. The Mission

"Probability is not a constant. Here, it is a predator."

Deep within the Cronus Hyper-Grid, Sector 7 has destabilized. The topology of the network has fractured into a stochastic mess of quantum states. We need to extract a stranded kernel from the core, but active navigation is impossible; the radiation lag is too high for real-time control.

You have been tasked with programming the Navigator Oracle. Since we cannot simulate the environment without collapsing the wave function, your only source of information is the "Black Box" Flight Log recovered from a previous, failed reconnaissance drone.

This drone moved blindly through the sector. It recorded its transitions, its actions, and the energy fluctuations (rewards) it encountered. It did not survive.

Note: For a visual representation of the topology and a baseline implementation, please refer to the PDF or the Jupyter Notebook (.ipynb) included in the starter kit.

Your Objective:
Using only this static, historical dataset, you must determine the True Optimal Value of specific starting states.

2. The Environment

Sector 7 is modeled as a Stochastic Markov Decision Process (MDP): M=⟨S,A,P,R,γ⟩\mathcal{M} = \langle S, A, P, R, \gamma \rangleM=⟨S,A,P,R,γ⟩.

  • States (SSS): A discrete set of nodes, identified by integers 0…N−10 \dots N-10…N−1.
  • Actions (AAA): A discrete set of 4 navigational impulses, identified by integers 0…30 \dots 30…3.
  • Dynamics (PPP): The transition function P(s′∣s,a)P(s' | s, a)P(s′∣s,a) is unknown and highly stochastic.
  • Reward (RRR): The reward function is noisy.
  • Discount (γ\gammaγ): The temporal discount factor is exactly 0.99.

Your task is to estimate the value of the optimal policy π∗\pi^*π∗ for a set of query states:

V∗(s)=max⁡πEπ[∑t=0∞γtrt∣s0=s]V^*(s) = \max_{\pi} \mathbb{E}_{\pi} \left[ \sum_{t=0}^{\infty} \gamma^t r_t \mid s_0 = s \right]V∗(s)=maxπ​Eπ​[∑t=0∞​γtrt​∣s0​=s]

File 1: sector_logs.csv

File 3: env.py

A Python definition of the environment class.

  • It defines the valid state space size, action space, and API structure.
  • It contains a step() method allowing for local simulation.

4. Evaluation & Scoring

You will be evaluated against a Ground Truth Solver that has access to the perfect underlying probability matrix of the simulation.

We compute the Mean Squared Error (MSE) between your predicted values V^\hat{V}V^ and the true optimal values V∗V^*V∗:

MSE=1K∑i=1K(V^(si)−V∗(si))2\text{MSE} = \frac{1}{K} \sum_{i=1}^{K} (\hat{V}(s_i) - V^*(s_i))^2MSE=K1​∑i=1K​(V^(si​)−V∗(si​))2

Your score is calculated based on two constants:

  • MSEbaseline=4000.0\text{MSE}_{\text{baseline}} = \mathbf{4000.0}MSEbaseline​=4000.0 (Upper Bound)
  • MSEoptimal=205.0\text{MSE}_{\text{optimal}} = \mathbf{205.0}MSEoptimal​=205.0 (Lower Bound)

The scoring follows a quartic curve:

Points=100×(MSEbaseline−MSEyoursMSEbaseline−MSEoptimal)4\text{Points} = 100 \times \left( \frac{\text{MSE}_{\text{baseline}} - \text{MSE}_{\text{yours}}}{\text{MSE}_{\text{baseline}} - \text{MSE}_{\text{optimal}}} \right)^4Points=100×(MSEbaseline​−MSEoptimal​MSEbaseline​−MSEyours​​)4

Constraints:

  • If MSEyours≥MSEbaseline\text{MSE}_{\text{yours}} \ge \text{MSE}_{\text{baseline}}MSEyours​≥MSEbaseline​, the term becomes negative (or zero) and you receive 0 points.
  • If MSEyours≤MSEoptimal\text{MSE}_{\text{yours}} \le \text{MSE}_{\text{optimal}}MSEyours​≤MSEoptimal​, the term exceeds 1 and is capped at 100 points.

Scoring Note:
The Baseline Threshold corresponds to the performance of a Naive Agent that blindly trusts the sparse data statistics or the provided simulation code. To score points, you must significantly outperform these heuristic approaches.
